# Portfolio mark

The split-S artwork is **Sssplit** by Fairpixels, distributed through [Logodust](https://logodust.com/).

- [Original SVG](https://www.dropbox.com/s/kqng792vgripaal/Sssplit.svg?raw=1)
- [License](https://logodust.com/license.html)

The original download is preserved in `logodust-sss-split.svg`. The two original paths are used in `public/favicon.svg`, recolored white, scaled and centered on the site's ink background. No font or icon library is required. The header loads this same SVG, and `scripts/generate-icons.mjs` derives the ICO and touch icon from it.
